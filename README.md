# EDCBViewer

録画機に溜まったファイルを手元の PC から探して再生するためのアプリです。  
ファイル名だけでは探しづらい番組も、タイトルや詳細説明のキーワードで EPG DB を全文検索できます。

## できること

**録画ファイルを探して再生する**  
SMB 共有された録画フォルダ（複数登録可）をまとめてブラウズし、見たいファイルをダブルクリックするだけで MPC-BE で再生できます。ファイルを選択すると、放送局・放送日時とともに番組情報が右ペインに表示されます。

**キーワードで番組を全文検索する**  
絞込ボックスにキーワードを入力して Enter を押すと、蓄積された EPG データを全文検索します（番組タイトル・あらすじ・詳細説明が対象）。出演者名や作品名など、ファイル名に含まれない情報でも番組を特定できます。

**番組表を見る（過去の日付も）**  
メニュー「番組表」で EPG 番組表を表示します。データソースは DB なので、EDCB 本体の過去番組表と違い、蓄積されている限り何日前でも遡れます。ジャンル色分け・現在時刻ライン付き。番組をクリックすると詳細を表示します。横スクロールはマウスの水平ホイール（MX Master のサムホイール等）に対応しています。

**EPG を自分で取り込む**  
起動時と「更新」時に、EDCB の EPG 蓄積ファイル（`*_epg.dat`）を読んで DB に取り込みます。EDCB 側には手を入れません。EpgTimerSrv も起動しません。

## 前提

- PostgreSQL（Supabase セルフホスト）が動いていること。EPG の蓄積先です
- 録画機の EDCB が EPG を蓄積していること。そのフォルダ（`Setting\EpgData`）を SMB で読めること
- 録画フォルダが SMB 共有されていること
- 手元の PC に .NET 9 Desktop Runtime と MPC-BE がインストールされていること
- **ビルドするマシンに EDCB がインストールされていること**（後述）

### EpgDataCap3.dll について

EPG の取り込みには EDCB 純正の `EpgDataCap3.dll` を使います。`*_epg.dat` は TS パケットの生ストリームで、EIT の解析と ARIB 8単位符号の復号をこの DLL に任せています。

この DLL はライセンス上の理由でリポジトリに含めていません。**ビルド時に EDCB のインストール先からコピーします。**

| | |
|---|---|
| 既定の参照元 | `C:\ap\edcb\EpgDataCap3.dll` |
| 配置先 | ビルド出力（`bin\Release\net9.0-windows\`） |
| 場所が違う場合 | `dotnet build -c Release -p:EpgDataCap3Dll=D:\path\to\EpgDataCap3.dll` |

参照元が見つからない場合、ビルドは成功しますが DLL は配られません。その状態で起動すると、EPG 取り込みだけが失敗します（一覧と検索は DB があれば動きます）。

デプロイはビルド出力フォルダごと配布してください。DLL はその中に入っているので、配布先に EDCB は不要です。

## セットアップ

```
dotnet build -c Release
```

ビルド後、`bin\Release\net9.0-windows\EDCBViewer.exe` を起動し、メニュー「設定 → パス設定...」で以下を設定します。

| 設定項目 | 例 |
|----------|----|
| DB 接続文字列 | `Host=5950X;Port=5432;Database=postgres;Username=postgres.xxx;Password=xxx` |
| EPG データフォルダ | `\\5600x\c\ap\edcb\Setting\EpgData`（空なら取り込まない） |
| フォルダ | `\\5600x\d\encoded` など（複数登録可、ブラウズの起点） |
| プレイヤー | `C:\ap\MPC-BE\mpc-be64.exe` |
| 表示件数 | 1 ページあたりの件数（デフォルト 500） |

`Host` は PostgreSQL が動いているマシン名です。`127.0.0.1` はそのマシン自身でしか通りません。

設定は `%LOCALAPPDATA%\EDCBViewer\settings.json` に保存されます。

## 操作

| 操作 | 動作 |
|------|------|
| フォルダをダブルクリック / Enter | フォルダに移動 |
| ファイルをダブルクリック / Enter | MPC-BE で再生 |
| 絞込ボックスに入力 | ファイル名（タイトル・放送局）でリアルタイムフィルタ（スペース区切りで AND） |
| 絞込ボックスで Enter | EPG 全文検索（番組タイトル・あらすじ・詳細説明） |
| 絞込ボックスをクリア | ファイルブラウズに戻る |
| メニュー「番組表」 | 番組表ウィンドウを開く（前日/今日/翌日・日付指定で移動） |
| F5 / 更新 | EPG を取り込んでからフォルダ再読込 |
| PageDown / PageUp | 次 / 前ページ |
| 印字可能文字（リスト選択中） | 絞込ボックスにフォーカスして入力 |
