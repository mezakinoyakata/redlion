# EDCBViewer

録画機に溜まったファイルを手元の PC から探して再生するためのアプリです。  
ファイル名だけでは探しづらい番組も、タイトルや詳細説明のキーワードで EPG DB を全文検索できます。

## できること

**録画ファイルを探して再生する**  
SMB 共有された録画フォルダ（複数登録可）をまとめてブラウズし、見たいファイルをダブルクリックするだけで MPC-BE で再生できます。ファイルを選択すると、放送局・放送日時とともに番組情報が右ペインに表示されます。

**キーワードで番組を全文検索する**  
絞込ボックスにキーワードを入力して Enter を押すと、MySQL に蓄積された EPG データを全文検索します（番組タイトル・あらすじ・詳細説明が対象）。出演者名や作品名など、ファイル名に含まれない情報でも番組を特定できます。

**番組表を見る（過去の日付も）**  
メニュー「番組表」で EPG 番組表を表示します。データソースは MySQL なので、EDCB 本体の過去番組表と違い、蓄積されている限り何日前でも遡れます。ジャンル色分け・現在時刻ライン付き。番組をクリックすると詳細を表示します。横スクロールはマウスの水平ホイール（MX Master のサムホイール等）に対応しています。

## 前提

- 録画機側で [mezakinoyakata/EDCB](https://github.com/mezakinoyakata/EDCB) が稼働し、MySQL へ EPG データを書き出していること
- 録画フォルダが SMB 共有されていること
- 手元の PC に .NET 9 Desktop Runtime と MPC-BE がインストールされていること

## セットアップ

```
dotnet build -c Release
```

ビルド後、`bin\Release\net9.0-windows\EDCBViewer.exe` を起動し、メニュー「設定 → パス設定...」で以下を設定します。

| 設定項目 | 例 |
|----------|----|
| MySQL 接続文字列 | `Server=5600x;Database=edcbviewer;Uid=edcb;Pwd=xxx` |
| フォルダ | `\\5600x\d\encoded` など（複数登録可、ブラウズの起点） |
| プレイヤー | `C:\ap\MPC-BE\mpc-be64.exe` |
| 表示件数 | 1 ページあたりの件数（デフォルト 500） |

設定は `%LOCALAPPDATA%\EDCBViewer\settings.json` に保存されます。

## 操作

| 操作 | 動作 |
|------|------|
| フォルダをダブルクリック / Enter | フォルダに移動 |
| ファイルをダブルクリック / Enter | MPC-BE で再生 |
| 絞込ボックスに入力 | ファイル名（タイトル・放送局）でリアルタイムフィルタ（スペース区切りで AND） |
| 絞込ボックスで Enter | EPG 全文検索（番組タイトル・あらすじ・詳細説明） |
| 絞込ボックスをクリア | ファイルブラウズに戻る |
| メニュー「番組表」 | 番組表ウィンドウを開く（前日/今日/翌日・日付指定で移動） |
| F5 | フォルダ再読込 |
| PageDown / PageUp | 次 / 前ページ |
| 印字可能文字（リスト選択中） | 絞込ボックスにフォーカスして入力 |
